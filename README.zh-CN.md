# Tool Bar Clock

这是一个在浏览器工具栏显示时钟的 Firefox 扩展。

## 功能

- 支持浏览器 IANA 时区数据中的全部时区。
- 通过输入框实时过滤时区。
- 默认使用浏览器检测到的本地时区。
- 保存用户选择的时区，并在工具栏时钟中显示对应时间。
- 支持自定义图标文字颜色和字体。
